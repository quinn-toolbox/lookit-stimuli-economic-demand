# lookit-stimuli-economic-demand

Stimuli for an Economic Demand study hosted on [Lookit](https://lookit.mit.edu/).

## Contents

| Folder | Contents |
|--------|----------|
| `mp4/` | Video stimuli (Conditions 1–4) |
| `webm/` | WebM versions of videos |
| `img/` | Images |
| `mp3/` | Audio (MP3) |
| `ogg/` | Audio (OGG) |

## Using with Lookit

Point your study’s `baseDir` at this repo:

```
https://raw.githubusercontent.com/YOUR_USERNAME/lookit-stimuli-economic-demand/master/
```

For a fixed snapshot, swap `master` for a commit ID.
